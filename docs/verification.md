# 验证记录

日期：2026-10-10。验证对象为 `npm run build` 生成的生产版，不依赖开发用状态修改接口。

- 6 项规则测试通过：加速、1612 N 断裂、松开卸力、可成功的制动策略、复位和断裂优先级。
- 46 项浏览器检查通过，未出现 JavaScript 运行异常或资源请求失败。
- 通过真实键盘、鼠标指针捕获和 Chrome CDP 触摸事件分别验证长按断裂与分段制动停车；失败及成功后的计时、车速和距离均保持停止。
- 验证了 Esc 暂停、恢复时清理输入、失去窗口焦点时暂停、画质与音量切换。
- 320×568、360×640、390×844、430×932、768×1024、844×390、1366×768 和 1920×1080 下，开始按钮与游戏控制均在视口内，无页面溢出。
- 可见界面不含车辆品牌名称。所有 6 个外部素材的下载 MD5 与来源记录匹配。

桌面使用本机 Chrome、Intel Iris Xe / ANGLE D3D11。手机检查采用 Chromium 的移动视口和触摸输入仿真，没有在实体 iOS / Android 手机上做硬件性能测量。

浏览器初始版本在 1600×900 下约 31 FPS；对照测量显示自动与高清后期效果约 34–37 FPS，流畅档约 59 FPS。默认档减少泛光成本并采用 1024 阴影贴图，修订版本同条件实测约 46 FPS。帧率随设备、画质和电源状态变化。后续地表贴图整合后做了完整生产版功能回归。

Windows 图形驱动对官方 Three.js FXAA / 光照着色器产生过精度提示；程序链接成功，截图中未发现渲染故障。这些提示记录在浏览器报告中。

本地完整报告：`artifacts/browser-report.json`；截图包括电脑和手机的初始、行驶、断裂及成功画面。
