日期：2026-10-11。本次验证包含生产网页、Windows x64 解包运行目录及实际便携 EXE。游戏源码哈希为 `f37c23a9ecf75860441ebb804a3b47ce081a3a9eeed2b6241301be00ae28e959`；最终 EXE 中的构建与当前游戏、资源、桌面主进程及通信桥逐项匹配。

13 项规则测试、68 项生产浏览器检查、15 项实际便携 EXE 离线检查、10 项便携 EXE 本机联动检查均通过。电脑、手机触控模拟和桌面成品均验证了正常停车与失败流程，未出现 JavaScript 异常或资源请求失败。

- 连续弯道、地面按世界距离滚动、固定地形纹理、逐块地形和逐棵树循环；长距离实测行驶约 1.78 公里，跨过旧场景重置位置。320、1360 米等边界的连续性有规则测试覆盖。
- 超过 100 km/h 显示制动建议，降至阈值以下隐藏。键盘和触摸均在输入处理器内反馈，踏板按压无 CSS 延迟，制动第一物理步生效。6 次性能抽样的下一次动画回调约 3.1–34.1 ms；该值不代表显示器最终呈现延迟。
- 1612 N 精确断裂、快速撞护栏、局部金属变形、偏斜车轮、碎玻璃、划痕、烟尘、保险杠脱落与报废静止。压力界限和事故推进使用固定步长，与帧率分离。
- 实际法庭场景、镜头、角色名牌和精确台词“你这是恶意刹车！”。所有产品中的标题和牌匾均为“法庭”。检查中发现镜头挤出车辆、椅子方向和人物坐席不合适，均修正并重新检查截图。
- 白天与暖色黄昏、太阳盘面及光晕、环境反射和路面光照切换；删除 HD / SD 按钮。8 种视口检查开始、驾驶和法庭控制，无页面溢出。实体手机硬件尚未测试。
- 便携 EXE 通过自身的本地协议读取内置文件，并在 CDP 对该页面完全禁网的条件下重新加载、完成事故与成功停车。不存在开发状态接口，游戏页面没有 Node 文件系统或进程接口。

桌面 QA 使用 GPU 离屏绘制和虚拟焦点，输入只发送给专用页面，没有发送全局键盘或鼠标。修复了隐藏测试窗口不持续绘制的问题。解包目录继承的 Windows ACL 阻止沙箱读取，已仅对 `release/win-unpacked` 增加 ALL APPLICATION PACKAGES 的只读/执行权限；没有关闭沙箱。

## 1.1 历史验证记录

日期：2026-10-10。验证对象为 `npm run build` 生成的生产版；浏览器检查通过正常键盘、鼠标、触摸操作完成，没有修改内部游戏状态。开发用 `?profile=1` 检查接口已由 Vite 从生产脚本中移除。

10 项规则测试、59 项浏览器检查与最终生产构建通过，未出现 JavaScript 运行异常或资源请求失败。

- 验证第一物理步立即减速、加速度提升、1612 N 精确断裂、松开卸力、分段制动停车、护栏碰撞反弹、损伤、报废静止，以及 60/120 步模拟结果的一致性。
- 使用真实键盘、指针捕获和 Chrome CDP 触摸事件分别验证长按失效、完整事故与成功停车。断裂后输入禁用、事故结束前不会弹出结算；按空格不会跳过事故。报废及成功后的计时、车速和距离保持停止。
- 键盘和触摸事件处理器内立即设置踏板按压状态；CSS 按压过渡为 0 秒。规则测试验证制动第一步就降低车速。原版有 140 ms 装饰动画，并等待压力爬升来增强制动；两处等待均已移除。
- 验证事故中的 Esc 暂停/恢复、恢复后保持刹车失效、窗口失焦暂停、声音开关与碰撞音效执行、画质切换和重试复位。
- 320×568、360×640、390×844、430×932、768×1024、844×390、1366×768、1920×1080 下，开始按钮与游戏控制均在视口内，无页面溢出。手机临界数值保持 16 px。
- 可见界面不含车辆品牌名称。6 个素材与 Poly Haven 元数据 MD5 匹配；2K 路面法线和 HDR 天空的 SHA-256 见 `public/assets/sources.json`。

6 次真实按键抽样均在事件处理器内反馈，下一次 rAF 回调约 9.5–20.8 ms。这是回调等待时间，不包含显示器最终呈现延迟。帧率也会随设备、电源与画质变化。

Windows 图形驱动对 Three.js 光照着色器出现过浮点精度提示；程序链接成功，截图中未发现渲染故障。提示记录在浏览器报告中。没有在实体 iOS / Android 手机上做硬件性能测量。
